# José Obras y Remodelaciones - Landing Page

Landing page diseñada para un emprendimiento de construcción y remodelaciones, enfocada en proyectar solidez, elegancia y confianza.

## Especificaciones de Diseño

El proyecto sigue un sistema de diseño enfocado en la usabilidad y experiencia del cliente, con un diseño limpio y moderno.

### 1. Paleta de Colores
- **Primario (Dorado):** `#D4AF37` - Utilizado para acentos, iconos y llamadas a la acción, evocando calidad y acabados profesionales.
- **Oscuro (Charcoal):** `#1A1A1A` - Color base para secciones de alto impacto y tipografía principal.
- **Fondo Suave:** `#F8F9FA` - Utilizado para dar descanso visual en secciones informativas.
- **Texto Muted:** `#666666` - Para descripciones y texto secundario.

### 2. Tipografía
- **Títulos:** `Outfit` (Weight: 900) - Una fuente geométrica y moderna que transmite fuerza y profesionalismo.
- **Cuerpo de texto:** `Montserrat` - Elegida por su legibilidad y versatilidad en entornos digitales.

### 3. Patrones de UI (User Interface)
- **Glassmorphism:** Las tarjetas de servicios y testimonios utilizan fondos con transparencia (`rgba`) y desenfoque (`backdrop-filter: blur(5px)`), creando una sensación de profundidad moderna.
- **Floating Cards:** Las secciones principales (Hero, Servicios, Testimonios y Footer) están diseñadas como tarjetas flotantes con bordes redondeados (`30px`) y un ancho máximo de `calc(100% - 60px)`, lo que permite que el diseño "respire" y luzca state-of-the-art.
- **Armonía Espacial:** Se ha implementado un espaciado vertical consistente de **120px** entre todas las secciones para mantener un ritmo visual equilibrado.
- **Navbar Dinámica:** Navegación fija con efecto de desenfoque y cambio de estilo al hacer scroll para mejorar la usabilidad.

### 4. Componentes Clave
- **Grid de Servicios:** Layout responsivo que utiliza `auto-fit` para adaptarse a cualquier tamaño de pantalla.
- **Galería de Proyectos:** Tarjetas con efectos de elevación (*hover transitions*) para mostrar el portafolio.
- **Secciones Oscuras Parallax:** Uso de imágenes de fondo fijas con capas de degradado para resaltar testimonios y servicios.

## Tecnologías Utilizadas
- **HTML5:** Estructura semántica.
- **CSS3:** Sistema de diseño basado en Variables CSS, Flexbox y Grid.
- **JavaScript:** Lógica para menú móvil, efectos de scroll y validaciones básicas.
